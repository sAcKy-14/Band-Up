# BandUp Web

Responsive product showcase for the BandUp vocabulary learning experience. The dashboard uses sample UI data to make the planned learning loop visible before authentication and API integration are added.

## Run locally

Requires Node.js 20 or newer.

```powershell
npm install
npm run dev
```

Open `http://localhost:3000`. The dashboard includes sample progress, vocabulary, collections, and review data. Buttons provide lightweight interactions so the prototype is easy to explore; data is not persisted.
